# Jeevandhara - Blood Donation Management System

## 📌 Overview
**Jeevandhara** is a web-based Blood Donation Management System designed to promote awareness about blood donation and provide a simple platform that connects blood donors with recipients.  

In today’s world, the demand for blood is very high due to medical emergencies such as accidents, surgeries, and critical illnesses. However, finding the right donor at the right time remains a major challenge. Jeevandhara addresses this problem by offering an easy-to-use and efficient solution.

---

## 🎯 Features
- **Donor Registration**: Users can register as blood donors by entering details such as name, blood group, and contact information.  
- **Search Functionality**: Patients and hospitals can search for donors based on specific blood groups.  
- **User-Friendly Interface**: Designed for simplicity and accessibility, even for users with minimal technical knowledge.  
- **Real-Time Processing**: Inputs are handled instantly, and results are displayed in real time.  
- **Community Engagement**: Encourages individuals, especially students and young people, to donate blood and contribute to society.  

---

## 🛠️ Tech Stack
- **Frontend**:  
  - React + TypeScript (modern, responsive, interactive UI)  
  - HTML & CSS (structure and styling)  

- **Backend (Current Version)**:  
  - JavaScript (handles user inputs and system functionality)  
  - *Note*: Current version does not include backend integration or permanent data storage.  

- **Future Enhancements**:  
  - Database integration (e.g., MySQL, MongoDB)  
  - User authentication & login system  
  - Advanced donor-recipient matching features  

---

## 🚀 How It Works
1. Donors register with their basic details.  
2. Recipients search for donors by blood group.  
3. The system instantly processes inputs and displays results.  
4. Simple, clean, and responsive interface ensures smooth navigation.
